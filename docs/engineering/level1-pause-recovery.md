# Level 1 Pause / Recovery Contract

Completed Level 1 includes a real pause state.

- Pause is a gameplay-local overlay; it does not mutate progression or navigation route.
- Board input is blocked while paused.
- Resume restores the exact current board.
- Restart reloads the same deterministic Level 1 attempt and re-arms teaching/feedback.
- Return to House exits without granting the Moon Cameo or advancing House state.
- Utility controls remain immediately recognizable; world translation is limited to material/copy, not icon semantics.
- Pause is included in visual journey evidence.

No paid dependency is involved.
