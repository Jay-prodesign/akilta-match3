# Level 1 Ritual Reward Presentation

Moon Cameo presentation is now shared between prestart and terminal win UI through a Match-3-owned procedural component. It intentionally uses House-native language—reliquary frame, crescent cameo, occult orbit seals, candle accents and Wax Seal—rather than generic stars, chests or gem reward shorthand.

This is original project code with no paid or external visual asset dependency.
