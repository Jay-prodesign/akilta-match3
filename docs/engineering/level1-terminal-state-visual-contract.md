# Level 1 Terminal-State Visual Contract

The terminal result now has two distinct world states:

- Win: the Moon Cameo reliquary glows and reads as awakened.
- Fail: the same reliquary remains dim, receives a central Wax Seal and crossed sealing marks, and does not visually grant the Curio.

This keeps reward semantics correct before progression is committed. Curio Collection content is also top-aligned so the awakened relic reads immediately rather than floating in empty vertical space.
