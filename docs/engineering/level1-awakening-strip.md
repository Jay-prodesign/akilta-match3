# Level 1 Awakening Strip

The unused lower portrait space in Level 1 is now purposeful rather than filled with a generic booster bar.

A House-native Awakening strip connects the match objective directly to the persistent Moon Cameo reward:
- six moon-seal marks visualize the authored 0/6 → 6/6 objective;
- the Moon Cameo medallion brightens at completion;
- copy reports remaining sigils and the final awakening;
- the strip reads from the same board-state objective truth as the HUD;
- no currency, monetization, booster or generic star grammar is introduced.

This is original project code and uses no paid asset.
