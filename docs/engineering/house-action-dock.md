# House Action Dock

The Level 1 House hub now uses a deliberate navigation hierarchy instead of three unrelated prototype buttons:

- Reliquary and Settings share one secondary action dock.
- Open Curio Map remains the single primary CTA.
- The Reliquary label reflects persistent Curio count.
- Existing navigation signals and first-party route authority remain unchanged.

This is an owned UI/layout refinement; no paid asset or template dependency is introduced.
