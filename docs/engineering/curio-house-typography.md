# Curio House Typography

Free/open typography is part of the Level 1 production direction.

- Cormorant Garamond: narrative display titles and House headlines.
- Manrope: global functional UI, body, button and settings typography.

Both files are vendored from pinned google/fonts commit bd8f81ddb5c74d5c8897b36ad88b440266245103 under SIL Open Font License 1.1. Binary hashes and OFL notices are stored in the repository. No paid font or typography service is used.
