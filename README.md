# AKILTA Match-3

AKILTA first-party mobile Match-3 game.

## Status

Pre-production research and product definition are complete enough to advance. G1 / Founder START is approved. Production implementation is beginning from a clean Godot baseline.

## Product authority

Google Drive remains the canonical source for product truth, roadmap, decisions, research and current state. This repository is the engineering source of truth for code, tests, runtime content/assets, build configuration and release engineering.

## Public-repository rules

This repository is currently public by Founder decision.

Do not commit:
- secrets or signing credentials;
- private provider keys;
- private research/source documents;
- unlicensed or provenance-unclear code/assets;
- donor product art/UI/levels;
- production credentials.

Third-party code is admitted only through the project donor/provenance gate.
